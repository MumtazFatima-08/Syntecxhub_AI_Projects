# Artificial Intelligence Projects - Syntecxhub

This repository contains the projects completed during my internship at Syntecxhub.

## 🧩 Project 1: Maze Solver using A* Search
A Python program that finds the shortest path through a grid-based maze using the A* Search algorithm and Manhattan distance heuristic.

## 🩺 Project 2: Rule-Based Expert System
A Python-based rule engine that acts as a basic diagnostic system. It uses forward chaining to infer potential conditions based on user-provided symptoms.
